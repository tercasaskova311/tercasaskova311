### 🔭 Currently working on

**Annotation-free tree crown detection.** DeepForest finds trees, SAM2 outlines their crowns, and simple rules decide what to keep, with no training labels at any step. Part of my thesis on the [3-30-300 urban green index](https://github.com/dclfbk/3-30-300-index), built on one DuckDB database. → [How it works](https://www.terezasaskova.com/portfolio/singletree-detection/)
